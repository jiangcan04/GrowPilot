# GrowPilot：四阶段导航与登录前端验证

日期：2026-10-27（北京时间）

## 本次结果

- 主导航按操作顺序固定为求职方向、成长计划、今日任务、我的积累。
- 求职方向内分目标岗位、能力对照；保留方向文件夹、筛选、岗位原文、动态要求词云、简历上传和能力证据。
- 能力对照明确区分已有基础、待提升部分和材料尚未证明的要求；生成建议后由用户决定是否加入本轮。
- 成长计划沿用统一建议清单及加入／已加入／取消加入状态；底部统一去执行。
- 今日任务默认汇总各方向，支持按方向筛选。每日时间预算共用，方向准备周期和方向内顺序分别保留。
- 日程保留约 15% 余量、前置步骤、完成历史、顺延和未排入周期提示。咕噜与今日列表使用同一队列顺序。
- 我的积累内分经历库、任务成果、信息与复盘；经历跨方向复用，成果支持文字、链接与任意格式文件，过程感悟选填。
- 成果 AI 整理入口生成可编辑草稿，可新增或补充已有经历，必须核查确认后写入，保留关联和版本。
- 独立登录页包含邮箱、演示验证码、重发倒计时、错误和过期提示、新用户昵称，以及有资料／空白两个演示账户入口。
- 左侧底部账户菜单提供个人设置、提醒与咕噜设置、切换账户、导出备份、重置当前账户、退出登录。
- 首次进入求职方向；再次登录且有进行中任务时进入今日任务。刷新保留会话与页面。
- 原浏览器记录首次迁入默认演示账户，默认账户沿用原附件数据库。不同演示账户的记录和附件分别保存；退出不删除数据。
- 切换或退出时，仅有未保存表单才提示；保存过程中阻止切换。

## 验证

- `npm test`：111 项 Node 检查和 14 项 Python 检查通过，共 125 项。
- `npm run build`：Worker ESM 构建通过，保留 20 个网页资源。
- `node --check`、`git diff --check` 通过。
- 通过受管理预览与浏览器 UI 验证：登录页布局、默认账户迁移、四项导航、能力对照下一步、经历库分类、成果编辑并确认补充经历、账户资料保存、空白账户隔离、退出、错误演示码提示、重新登录恢复资料与今日任务、刷新保留状态、自定义任务加入与统一排程、两方向任务汇总、方向筛选、每日总时长设置，以及有未保存提问时取消退出后保留内容。
- 桌面截图检查登录页、今日列表、账户菜单和成果核对表单。

## 范围

此版本只实现前端交互示例。登录不发送邮件、不验证邮箱所有权、不提供服务器身份验证或跨设备同步；AI、岗位采集与全网经验检索仍为明确标注的示例。提醒不会在网页关闭后推送，咕噜为网页内伙伴。未更改网站地址、网站访问范围或后台接口。
