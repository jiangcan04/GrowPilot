# 2026-10-26 修改与验证记录

## 已实现

- 发现岗位在前，方向文件夹在后；一个岗位可归入多个方向，归档后可恢复。
- 各方向独立汇总岗位要求和雷达图，保留原文、来源、必备标记与计算口径。
- 简历文件在浏览器本机解析，提取经历草稿并人工核查；共同经历库跨方向复用。
- 匹配结果分为已核对关联、需要补充实践、暂不确定；不得把没有证据直接当作没有能力。
- 时间安排联动；建议有岗位原文、案例或实践路径、预计投入、步骤、产出和完成标准。
- 自定义任务和建议修改、采纳/不采纳保留；缺少参考依据时阻止直接采纳自动建议。
- 多文件、多链接的任务成果草稿/最终提交；经核查后转入经历库。
- 外部信息、面试思考和执行想法的结构化记录，并可转换为自定义任务。
- 删除申请进度、投递历史与沟通草稿。
- 旧版数据迁移、存储失败提示和 ZIP 备份。

## 自动验证

运行 node --test tests/core.test.cjs。覆盖方向要求隔离、经历复用、雷达去重、草稿核查、依据失效、建议去重、未知技能的参考材料缺口、日期联动、旧版迁移和简历草稿提取。

运行 node --check dist/core.js 和 node --check dist/app.js 检查语法。

## 浏览器验证（合成测试材料）

- 创建 AI 产品和 AI 运营两个方向，分别收藏不同岗位，检查雷达和要求独立更新。
- 导入 DOCX 简历，得到待核查草稿；人工确认事实，并将经历关联到指定要求。
- 将其他要求标记为待补实践或待核实，确认本轮后生成对应建议。
- 设置 60 天、每日 2 小时，验证截止日和 120 小时预算。
- 采纳任务并完成四个步骤，填写方法、结果、感悟，附 Markdown 与 PDF 文件及一个链接，提交最终成果。
- 刷新页面后成果、附件条目与完成状态保留；点击打开 PDF 产生相应 Blob 页。
- 将任务成果整理为经历，需要显式核查事实；切换产品方向后可复用共同经历库。
- 保存面试思考和后续学习事项。
- 导入独立 PDF 测试简历，成功提取文字并建立待核查草稿。
- 验证单独新建方向、手动岗位录入、自定义任务和参考材料关联；缺少案例时阻止采纳，人工补齐并核查后可以采纳。
- 修复并复测隐藏 id 字段导致部分表单无法保存的问题。
