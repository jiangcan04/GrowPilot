# 2026-10-26：所选 JD 自动匹配更新

## 行为

1. 收集岗位与选入本轮匹配分别存储。各方向独立选择，可清空或全选。
2. 选中 6 条时，输入、要求频次、雷达图和后续任务只使用这 6 条，未选中的 4 条保留在方向文件夹。
3. 相同及近义要求归并；单个岗位独有的要求保留。技能程度差异保留在原文依据内。
4. 简历和补充经历可直接参与匹配，不再要求逐项人工确认。可选纠错绑定本轮输入快照，材料变化后自动失效。
5. 真实 AI 与规则预览分别标记。结果包含状态、个人材料引文、理由、缺口、下一步、JD 原文及频次。
6. 新增公开链接批量读取、采集 JSON 导入和本机 AI 接口。读取失败逐条报告，不用虚构结果填补。
