# 每日任务与小鸟陪伴

- 准备计划底部统一入口，展示进行中计划数与预计投入；无计划时禁用。
- 当前方向的已加入计划按 JD 必备程度、频次、能力差距、已有积累进行本地规则排序；显式前置关系先执行，循环依赖阻止安排。
- 展示计划编号、排序原因、手动提前/稍后和恢复推荐顺序；完整步骤与材料保留。
- 步骤按分钟拆入每日，留出 15% 余量，扣除其他方向同期任务占用。超出准备周期的分钟数明确提示。
- 今日任务先显示，支持日期查看、完成/撤销、阶段成果登记、今日剩余时间调整。填 0 顺延，保留已完成记录与成果；调序不覆盖今日可用时长。新一天访问时更新每日安排。
- 代码绘制小鸟陪伴，轻微呼吸/挥翅，可收起和减少动效，尊重系统减少动效偏好。当前任务提示、拆小一步、材料入口与今天做不完均可操作。
- 提醒时间与通知样式仅前端展示，不申请系统通知权限，不实际推送，不调用 AI。

验证：88 项 Node 测试与 14 项 Python 测试通过；JavaScript 语法与 Worker ESM 产物检查通过。浏览器核对统一入口、今日分配、完成反馈、顺延保留完成记录、提醒时间保存、手动调序、小鸟收起、任务材料与通知样式。预览截图核对页面与小鸟可见。
