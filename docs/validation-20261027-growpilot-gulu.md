# GrowPilot 与全页面咕噜

保留原小鸟的 SVG 形象与颜色，仅移除背景面板，名称改为咕噜。浏览器标题、品牌、页头、提醒与备份文件名统一为 GrowPilot；内部存储键及 API 契约不变，保留旧记录。

咕噜挂载在主内容之外，五个页面共享位置、收起和动效偏好。支持鼠标和触摸 Pointer Events 拖动，超过 5px 才判断为拖动，拖动后不误打开气泡。位置保存在现有浏览器数据内，缩小窗口时限制在可见范围；支持方向键移动与恢复默认位置。小鸟本体不透明，颜色完整，只有背板移除。

气泡点击打开/关闭，切换页面不重复自动弹出，每日首次访问最多自动提醒一次。内容依据各方向实际今日任务、完成记录与当前页面；没有记录时不推断用户拖延或完成。带我开始可切换方向、更新过期安排并定位下一未完成步骤。气泡提供今日任务、页面下一步、困难帮助、材料、时间调整与成果登记。模态弹窗层级高于咕噜。

前端交互示例，无真实 AI 对话或系统推送。

验证：92 项 Node 测试与 14 项 Python 测试通过，语法和 Worker ESM 产物检查通过。浏览器核对 GrowPilot 品牌、完整彩色小鸟无背板、五页面持续存在、鼠标拖动不误开气泡、位置跨页面及刷新保存、收起恢复、页面引导、恢复默认位置、今日任务定位和时间调整。
