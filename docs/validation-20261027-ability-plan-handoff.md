# 能力匹配与本轮计划选择

前端修改：
- 经历与对照分为已具备能力、岗位要求中待提升能力两栏，保留简历／经历依据与岗位原文。
- 已具备基础和待提升部分可同时体现；信息不足单独等待补充，不直接判定为不具备。
- 单项或批量“AI 生成求职成长建议”进入准备计划，创建或复用待选择建议，不自动采纳。
- 准备计划只负责查看、调整、加入或暂不加入本轮，生成入口统一放在能力匹配页。
- 新初始化资料不提前创建待选择建议；示例中的历史／进行中任务保留。
- 页面不再使用“补强”名称。后端、成果登记、经历库与时间安排保留。
