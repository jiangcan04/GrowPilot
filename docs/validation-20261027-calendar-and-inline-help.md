# GrowPilot：任务日历与原位帮助

日期：2026-10-27（北京时间）

## 界面变化

- 工作台沿用登录页的浅绿、暖白、柔和圆角与统一主按钮配色，保留咕噜原 SVG 形象及拖动。
- 今日任务直接说明任务来源及执行方式，并以当前实际任务展示做法示例。
- 每项任务直接显示方向、时长、做法摘要和本步成果。
- 完成记录、本轮成长任务、排序说明与管理入口直接显示。
- 周／月日历展示各方向已安排的任务、预计分钟数与完成状态，支持翻周／月、回到今天、日期选择和方向筛选。
- 日历来自已有排程记录，不虚构具体开始时间。未排入周期的内容继续提示。
- 已加入任务首次进入今日页时自动形成示例日程，不必再点击初始化。
- 点击开始后显示与确认的 UI 图一致的单任务执行工作面：当天任务条、具体做法、成果、完成标准、材料链接、任务内帮助及完成／成果登记按钮。
- 取消任务主体内的折叠入口。较长的原始资料和必要设置仍由独立入口承接。
- 轻量单行提问栏始终可见，支持 Enter 发送和 Shift+Enter 换行，不显示模型选择或附件工具栏。
- 问答仅更新当前任务内的对话区域，保持任务内容和输入控件；全部历史可在小型滚动区域连续阅读。
- 看例子、拆小步骤在原位显示。拆解直接编辑、确认采用，可在开始执行前撤销；已执行后保留进度。
- 咕噜在当前任务中的提问入口聚焦同一输入栏，全站入口明确为继续今日任务。
