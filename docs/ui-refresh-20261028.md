# GrowPilot UI 更新 · 2026-10-28

本次更新同步当前新版演示站的完整网页代码，保留原有求职流程、浏览器数据、后端文件及仓库部署标识。

## 界面与品牌

- 主视觉为黑白灰，使用 `#e2f238` 荧光黄强调主要操作与选中状态。
- 新标志、横向字标、SVG 与 PNG 网站图标位于 `web/assets/brand/`。
- 能力对照、匹配面板、步骤条及成长计划卡片统一为中性灰，保持信息层级。
- `ramp-theme.css` 是当前界面的主题；早期 `calendar-theme.css` 保留作样式存档，没有在入口页加载。

## 咕噜与词云

- 咕噜保留原 C 折纸小鸟，新增表情、目光跟随、摸摸、拖动落稳、打招呼、短距离走动与小憩。
- 25 分钟专注计时在当前页面内提醒，按账户保存时间戳；计时结束不会自动完成求职任务。
- 只有用户确认完成任务后才触发完成庆祝；账户切换清理临时表情和待执行点击。
- 词云改用连续轨迹和速度缓入缓出，保留需求键、提及频次及原文入口；悬停、聚焦、按钮暂停和减少动效均有效。
- 本地开发与 Worker 构建支持 SVG、PNG 的正确 MIME 类型；Worker 构建兼容 Windows 换行。

## 验证

- JavaScript：142 项测试通过，包含 13 项咕噜交互测试、6 项词云测试，以及原有业务流程测试。
- 每日提醒的测试样例固定日期，避免随执行日期变化而失效。
- 浏览器已检查主题、品牌资源、咕噜互动、词云暂停与继续、SQL 岗位原文入口。
- Python 兼容服务的 14 项测试通过；Worker 构建及 ESM 产物检查通过。构建产物 `dist/` 不进入版本控制。
