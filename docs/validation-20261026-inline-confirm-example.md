# 建议内嵌经验、成果确认同步与完整案例示例

## 本轮变更

- 取消独立经验和学习材料模块；每条建议包含对应的经验分享、案例、岗位关联、来源链接及课程/资料。支持更新和补充当前建议，补充链接可编辑。
- 自选准备天数输入取代固定周期按钮，天数、截止日期、周数、每日时长与预算联动。
- 识别成果仅创建待确认草稿；用户可修改内容与分类，勾选核查并确认才写入经历库。取消、原成果变化或重复加入均不写入。真实模型未配置时提供同样需要预览确认的手动整理。
- 完整示例使用独立内存状态。示例人物、岗位、匹配和成果明确虚构；示例关联真实公开文章但不声称实时抓取。预置识别明确不是实际模型调用。
