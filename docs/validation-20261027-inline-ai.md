# 页面内 AI 与成果登记前端验收

范围：仅前端 UI、本地演示交互、页面内示例资料；没有修改 worker 或 Python 后端。

## 交付

移除完整案例入口与概览模式。正常页面提供标注样例和表单填充。新增带当前方向与材料范围的 AI 侧栏，覆盖岗位解读、简历提取、匹配解读、计划调整、经历更新和复盘。方案先比较、编辑、确认，再写入本地任务。

成果登记必填名称、成果内容和描述；文字、链接、文件可组合，上传格式不限（每个15MB）。过程与想法选填。任务可有多份成果，保存不改变任务完成状态。双栏整理区展示原材料、未读取状态、待确认草稿、分类、新增／补充已有条目和确认。更新保留版本，关联成果不能重复新增。

## 验证

- 70项Node检查与14项Python回归通过；Worker构建和ESM校验通过。
- 浏览器验证匹配解读与快捷追问、计划前后对比和确认采用。
- 未填写过程／方法／感悟，任务步骤未勾完，仍能登记文字成果并打开整理区。
- 成果新增为课程经历：确认前库中4条，确认后5条；再补充已有项目经历后仍5条。
- 重载后保留人工修改的经历文本，修改记录可查看。独立完整案例入口不存在。
- 检查了双栏工作区、成果卡片、助手侧栏和本地状态提示。新旧数据兼容，已有资料不被初始化示例覆盖。

未验证或实现实际模型、全网搜索、附件AI解析及云端数据库；页面清楚标记为前端交互示例。
