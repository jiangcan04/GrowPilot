# 求职成长建议前端优化验收

范围：只修改前端与前端示例，不实现全网检索、模型分析或真正的排程服务。后端 worker 与 Python 服务源码未修改。

- 准备计划拆为时间与重点、优先补强建议、已加入任务；卡片显示优先原因、复用基础、投入和交付。
- 每条建议内折叠显示差距与执行步骤、方向检索示例、参考经验、课程链接，不设独立案例模块。
- 支持选择信息补充、经历整理、证明材料、已有实践补充或学习实践等示例做法，确认弹窗联动交付与工时。
- 用户自定天数，预算变化会改变示例优先安排与暂缓原因。加入前确认日期和投入，取消不新增任务。
- 相同类型与能力方向合为一个建议，覆盖多个要求；已加入任务不重复生成，暂不考虑后允许新建议。
- 保留自定义任务、历史任务、成果与用户编辑过的新版建议。
- 完整示例使用预置材料；不发起搜索或 AI 请求，退出后恢复真实记录。

验证：62 项 Node 检查与14项 Python 回归通过，ESM构建有效。浏览器实际验证了案例折叠、做法切换、取消不加入、确认后出现在任务列表、任意准备天数与预算不足后的暂缓展示。最终截图检查卡片无溢出。后续针对前端补充的语句变更重跑受影响检查和构建。
